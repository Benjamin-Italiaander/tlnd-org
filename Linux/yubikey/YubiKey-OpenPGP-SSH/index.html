🔐 YubiKey + GPG + SSH Setup Guide Link to heading

in deze handleiding ben ik het onderwerp kdf-setup vergeten, dit moet ik nog toevoegen.

🎯 Doel Link to heading

  • GPG subkeys op YubiKey zetten
  • SSH authenticatie via YubiKey gebruiken
  • Werken met ProxyJump / multi-hop SSH

1. 🔍 Check bestaande GPG keys Link to heading

gpg -K --with-keygrip

Voorbeeld:

sec#  ed25519 ... [C]
ssb   ed25519 ... [S]
ssb   cv25519 ... [E]
ssb   ed25519 ... [A]

Betekenis Link to heading

TypeBetekenis
[S]Signing
[E]Encryption
[A]Authentication
sec#master key niet lokaal
ssb>key staat al op YubiKey
ssbkey staat lokaal

2. 🔐 Check YubiKey status Link to heading

gpg --card-status

Controleer:

  • serial number
  • welke keys aanwezig zijn
  • PIN retry counters

3. 💾 Backup (BELANGRIJK) Link to heading

gpg --export-secret-subkeys benjamin.italiaander@cwi.nl > secret-subkeys-backup.asc
chmod 600 secret-subkeys-backup.asc

4. 🔑 Subkeys naar YubiKey kopiëren Link to heading

gpg --edit-key benjamin.italiaander@cwi.nl

⚠️ Belangrijk Link to heading

key N is een toggle — zorg dat exact 1 key geselecteerd is

Controleer met:

list

5. ✅ Controle Link to heading

gpg --card-status

Je wilt zien:

Signature key ....: ...
Encryption key....: ...
Authentication key: ...

6. 🔑 SSH public key exporteren Link to heading

gpg --export-ssh-key benjamin.italiaander@cwi.nl

Opslaan:

gpg --export-ssh-key benjamin.italiaander@cwi.nl > ~/.ssh/yubikey.pub

7. 🖥️ Public key op server zetten Link to heading

mkdir -p ~/.ssh
chmod 700 ~/.ssh
nano ~/.ssh/authorized_keys

Plak de key en:

chmod 600 ~/.ssh/authorized_keys

8. ⚙️ gpg-agent configureren Link to heading

Bestand:

~/.gnupg/gpg-agent.conf

Inhoud:

enable-ssh-support
pinentry-program /usr/bin/pinentry-curses

9. 🔄 Agent herstarten Link to heading

gpgconf --kill gpg-agent

10. 🧠 Environment variables Link to heading

Zet in ~/.bashrc Link to heading

export GPG_TTY=$(tty)
export SSH_AUTH_SOCK=$(gpgconf --list-dirs agent-ssh-socket)

gpg-connect-agent updatestartuptty /bye >/dev/null 2>&1

Daarna:

source ~/.bashrc

11. 🔍 Check SSH agent Link to heading

ssh-add -L

Je wilt zien:

ssh-ed25519 ... cardno:XXXX

12. 🔗 SSH config voorbeeld Link to heading

Host doorgang.cwi.nl
    User italiaan
    IdentityFile ~/.ssh/id_ed25519

Host turku-proxy
    HostName 192.16.191.110
    User benjamin
    ProxyJump doorgang.cwi.nl
    ForwardAgent yes

Host cwi-www-proxy
    HostName 192.168.214.4
    User root
    ProxyJump turku-proxy
    ForwardAgent yes
    IdentitiesOnly no

13. 🔍 Debugging Link to heading

ssh -vvv cwi-www-proxy

Zoek naar:

Offering public key: cardno:...
Server accepts key: cardno:...

14. ⚠️ Veelvoorkomende problemen Link to heading

❌ Verkeerde agent Link to heading

echo $SSH_AUTH_SOCK

Moet zijn:

/run/user/.../gnupg/S.gpg-agent.ssh

Niet:

/run/user/.../keyring/ssh

❌ Signing failed / agent refused Link to heading

Fix:

export GPG_TTY=$(tty)
gpg-connect-agent updatestartuptty /bye

❌ Verkeerde key gebruikt Link to heading

Check:

ssh-add -L

❌ Server accepteert key niet Link to heading

Vergelijk:

gpg --export-ssh-key benjamin.italiaander@cwi.nl

met:

~/.ssh/authorized_keys

15. 🧪 Snelle checks Link to heading

gpg --card-status
gpg -K
ssh-add -L
echo $SSH_AUTH_SOCK
ssh -vvv host

🧠 Samenvatting Link to heading

  • ⚙️ env vars → in .bashrc
