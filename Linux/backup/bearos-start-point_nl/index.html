De eerste basis van Bareos

De belangrijkste onderdelen van Bareos

Bareos bestaat uit deze hoofdonderdelen of diensten:

  • Bareos Director Service
  • Console Service
  • Bareos File Daemon
  • Bareos Storage Daemon
  • Bareos Monitor Service

Bareos Director Service

De Director is het centrale besturingsprogramma voor alle andere daemons. Hij plant en bewaakt alle back-up-, herstel-, controle- en archiveringstaken. De systeembeheerder gebruikt de Bareos Director om back-ups in te plannen en bestanden terug te zetten. De Director draait als daemon (of dienst) op de achtergrond.

Console Service

Het programma bconsole praat met de Director en laat de gebruiker of systeembeheerder Bareos besturen.

Bareos File Daemon

De Bareos File Daemon is een programma dat op elke (client)machine moet staan waarvan een back-up wordt gemaakt. Op verzoek van de Bareos Director zoekt hij de bestanden voor de back-up en stuurt hij ze (hun gegevens) naar de Bareos Storage Daemon. Hij is specifiek voor het besturingssysteem waarop hij draait en levert de bestandskenmerken en gegevens wanneer de Bareos Director daarom vraagt. De Bareos File Daemon zorgt bij het terugzetten ook voor het bestandssysteemafhankelijke deel van het herstellen van bestandskenmerken en gegevens. Dit programma draait als daemon op de machine waarvan een back-up wordt gemaakt.

Bareos Storage Daemon

De Storage Daemon, soms SD genoemd, is de code die de kenmerken en gegevens naar een opslagvolume schrijft (meestal een tape of schijf). Op verzoek van de Bareos Director neemt de Bareos Storage Daemon gegevens aan van een Bareos File Daemon en slaat hij de bestandskenmerken en gegevens op de fysieke back-upmedia of volumes op. Bij een herstelverzoek zoekt hij de gegevens op en stuurt hij ze naar de Bareos File Daemon. Je kunt meerdere Bareos Storage Daemons hebben, allemaal bestuurd door dezelfde Bareos Director. De Storage-dienst draait als daemon op de machine met het back-upapparaat (zoals een tapedrive).

Bareos Monitor Service

Het programma dat met alle daemons praat en de gebruiker of systeembeheerder de status van Bareos laat volgen.

# estimate shows what a job will back up
estimate job=MyFirstJob listing

# run job
run job=MyFirstJob yes

# list running jobs on the client
status client

list jobs
